页面栈是微信小程序、uni-app（基于小程序规范）中特有的路由管理机制，理解它有助于搞清楚页面跳转、返回以及页面生命周期之间的关系。

## 什么是页面栈、压栈、出栈？

栈是一种后进先出的数据结构：

- **压栈（push）**：打开新页面，把新页面塞进栈的最顶部。
- **出栈（pop）**：点击左上角返回，把栈最顶部页面删掉，回到上一页。

举个例子：

1. 打开首页（tab 页面）→ 栈：`[首页]`
2. 首页点击按钮 `navigateTo` 打开服务历史页 → 压栈，栈：`[首页，服务历史]`
3. 点返回箭头 → 出栈，删除服务历史页，回到首页，栈：`[首页]`

## 页面栈是小程序 / uni-app 特有机制

传统网页浏览器没有这套页面栈规则：

1. **网页**：依靠浏览器历史记录管理前进后退，页面不会常驻内存，跳转默认销毁旧页面。
2. **小程序 / uni-app**：为了移动端 APP 体验，自研页面栈管理，页面可以缓存驻留内存、区分 tab 页面和普通页面，生命周期更细致。




### onLoad(options)

含义：页面加载初始化生命周期，页面创建时触发，一辈子只执行 1 次。

- **作用**：接收跳转过来的路由参数 `options`、页面首次初始化、初次请求接口。
- **触发条件**：页面被全新创建实例的时候才会执行。
- **注意**：一旦页面实例被创建完毕、没有被销毁，永远不会再次执行 `onLoad`。

### onShow

含义：页面被展示、切换到前台可见状态时触发，可反复执行无数次。

触发场景：

1. 页面初次创建，`onLoad` 执行完毕后，必定紧跟着执行一次 `onShow`。
2. 从子页面返回上一页。
3. 点击底部 tab 来回切换。
4. 手机切后台再切回小程序。

只要页面从「隐藏」变成「可见」，就会触发 `onShow`。

## 配套两个常用反向生命周期

- **onHide**：页面被切换到后台、看不见了，触发。
- **onUnload**：页面实例被彻底销毁、内存释放，只会执行 1 次，销毁后一切状态清空。

## tabBar 页面 / 普通非 tab 页面 生命周期差异

### 类型 A：底部 tab 页面（首页、我的、统计页这类 tab 菜单页面）

核心特性：

1. 项目初始化加载后，所有 tab 页面会提前初始化进入页面栈底部，永久常驻内存，永远不会触发 `onUnload`（永远不会被销毁）。
2. `onLoad`：每个 tab 页面全局仅执行 1 次。
3. 反复点击底部 tab 切换：只会来回触发 `onShow ↔ onHide`，绝不会走 `onLoad`。

时序演示：

1. 第一次点开首页 tab：`onLoad`（1 次）→ `onShow`
2. 点「我的」tab：首页执行 `onHide`；我的执行 `onShow`
3. 再切回首页：首页执行 `onShow`，无 `onLoad`

### 类型 B：跳转到普通页面（navigateTo 跳转打开的二级页面）

特性：页面随时会被销毁，销毁后再次打开会完整重建页面。

**场景 1：navigateTo 跳转 + 左上角返回（出栈）**

1. 首页（tab）`navigateTo` 打开服务历史页：服务历史全新创建 → `onLoad` → `onShow`，页面栈：`[首页, 服务历史]`
2. 点击返回箭头：服务历史页面执行 `onUnload`（彻底销毁）、出栈；首页触发 `onShow`，栈变回：`[首页]`

👉 页面销毁，本地所有变量、请求缓存全部清空。

**场景 2：跳转到 tab 页面，直接点击底部其他 tab（switchTab 切换 tab）**

小程序硬性规则：一旦调用 `switchTab` 切换底部 tab，系统会清空页面栈内所有非 tab 普通页面，全部执行 `onUnload` 销毁。

时序：

1. 栈：`[首页, 服务历史]`
2. 直接点击底部「我的」tab
3. 服务历史页面立刻销毁（`onUnload`），页面栈只剩所有 tab 页面
4. 展示「我的」tab 页面

## 跳转方式

| 跳转 API | 使用场景 | 页面栈变化 | 切底部 tab 后果 |
| --- | --- | --- | --- |
| `navigateTo` | 打开详情、二级页面（最常用） | 新页面压入栈顶，上一页保留 | 栈内所有普通页面全部销毁 |
| `redirectTo` | 替换当前页面，无返回箭头 | 销毁当前页，新页面替换它的位置 | 剩余普通页面依旧会被销毁 |
| `switchTab` | 切换底部导航 tab | 清空全部非 tab 页面，只保留 tab 页面 | 本身就是切 tab 动作，清空子页面 |
| `reLaunch` | 关闭所有页面，打开首页 | 页面栈全部清空重建 | 整个小程序重启，所有页面销毁 |
